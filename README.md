# Knapsack Problem (DAA Project)

## Overview
Real-life application of the **0/1 Knapsack Problem** to maximize profit under weight constraints (e.g., drone delivery system).

## Approach
- **Dynamic Programming (DP)**
- Optimal and efficient compared to Greedy and Backtracking

## Complexity
- Time: O(nW)  
- Space: O(nW)  

## Language
- C
